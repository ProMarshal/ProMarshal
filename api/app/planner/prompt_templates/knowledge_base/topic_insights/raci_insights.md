# RACI Topic Insights

## Real-World Experience

### Do's
- Build RACI for decisions and deliverables, not activities - it's about accountability, not task tracking
- Limit to ONE Accountable per item - multiple A's is an anti-pattern that causes confusion
- Use RACI for contentious areas first - where confusion/conflict exists, not everywhere
- Review RACI when roles change - it goes stale as people join/leave
- Keep it simple - if RACI takes longer to maintain than it saves, it's too detailed

### Don'ts
- Don't create RACI bureaucracy - it's a clarification tool, not a governance layer
- Don't make the matrix too granular - 50 line items is too many; 5-10 key areas is right
- Don't skip the Informed column - people left out feel excluded and create resistance
- Don't treat RACI as set in stone - revisit it when things aren't working

### Warnings
- Too many C's (Consulted) slows down decisions - only include those whose input genuinely changes outcomes
- RACI created but never referenced is waste - use it or lose it
- When everyone is Responsible, no one takes initiative - clarify who leads each item
- RACI won't solve political problems - it surfaces them, which is useful, but doesn't fix them

### Recovery Tips
- If decisions are slow, audit the C's - probably too many people in the loop
- If balls are being dropped, check for items with no clear A - someone must own each thing
