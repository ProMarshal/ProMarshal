# Implementation Project Context

## Project Type Overview
Implementation projects focus on deploying and integrating existing software, systems, or processes into an operational environment. The outcome is typically an operational system, trained users, and changed business processes.

## Key Terminology
When discussing this project type, use and understand these terms:

| Term | Meaning in This Context |
|------|-------------------------|
| Go-Live | Date when system becomes operational |
| Rollout | Phased deployment to user groups |
| Configuration | Adjusting system settings (not coding) |
| Customization | Changes beyond standard configuration |
| Data Migration | Moving data from old to new system |
| Change Management | Managing people side of change |
| User Adoption | Getting users to actually use the system |
| Training | Teaching users to use the system |
| Hypercare | Intensive support immediately after go-live |
| UAT | User Acceptance Testing before go-live |
| Cutover | Transition from old to new system |
| Parallel Running | Running old and new systems simultaneously |
| SLA | Service Level Agreement for support |
| Vendor | Third-party software provider |
| Integrator | Partner implementing the solution |
| COTS | Commercial Off-The-Shelf software |
| OCM | Organizational Change Management |
| Business Process | Workflow or procedure being changed |

## What to Probe Specifically

### Goal
- What business process is being improved?
- What system is being replaced or enhanced?
- What efficiency gains are expected?
- How will success be measured post-implementation?

### Scope
- Which business units or locations?
- What processes are included/excluded?
- What integrations with existing systems?
- Customization vs configuration approach?

### Schedule
- What's driving the timeline (contract, fiscal year, regulatory)?
- Training lead time before go-live?
- Data migration timeline and complexity?

### Rollout Phase
- Big bang or phased approach?
- Pilot group selection criteria?
- Regional or functional phasing?
- Fallback/rollback options?

## Intelligent Behaviors for Implementation Projects
- Emphasize change management and adoption
- Flag data migration complexity
- Recommend pilot before full rollout
- Connect training to adoption success
- Identify vendor/integrator dependencies
- Consider business continuity during transition
- Plan for hypercare support
- Address user resistance proactively
