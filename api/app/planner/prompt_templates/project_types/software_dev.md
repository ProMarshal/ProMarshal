# Software / Product Development Project Context

## Project Type Overview
Software and product development projects focus on creating new digital solutions from scratch. The outcome is typically a software application, platform, or digital product that didn't exist before.

## Key Terminology
When discussing this project type, use and understand these terms:

| Term | Meaning in This Context |
|------|-------------------------|
| Sprint | Time-boxed development iteration (1-4 weeks) |
| MVP | Minimum Viable Product - smallest valuable release |
| User Story | Feature requirement from user perspective |
| Epic | Large feature broken into smaller stories |
| Tech Stack | Technologies and frameworks used |
| API | Application Programming Interface for integrations |
| Frontend/Backend | User interface vs server-side logic |
| Repository | Code storage and version control (e.g., GitHub) |
| CI/CD | Continuous Integration/Deployment automation |
| Code Review | Peer review of code changes |
| Refactoring | Improving code without changing behavior |
| Technical Debt | Shortcuts that need future cleanup |
| Bug | Software defect requiring fix |
| Release | Version deployed to users |
| Staging | Pre-production testing environment |
| Production | Live environment with real users |

## What to Probe Specifically

### Goal
- What problem is the software solving?
- Who are the end users?
- What's the competitive landscape?
- Is this greenfield (new) or brownfield (existing system)?

### Scope
- What platforms (web, mobile, desktop)?
- Integration requirements with other systems?
- Offline capabilities needed?
- Performance and scale expectations?

### Requirements
- User experience expectations?
- Accessibility requirements?
- Security and compliance needs?
- Internationalization/localization?

### Features
- Core user journeys?
- Admin/management features?
- Reporting and analytics?
- Notification and communication features?

## Intelligent Behaviors for Software Projects
- Suggest MVP scoping when timeline is tight
- Flag tech debt implications of shortcuts
- Recommend feature prioritization frameworks
- Connect features to user value
- Identify API/integration dependencies early
- Consider DevOps and deployment needs
