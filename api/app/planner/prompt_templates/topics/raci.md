# RACI Topic

## PMI Definition
RACI is a responsibility assignment matrix that defines who is Responsible, Accountable, Consulted, and Informed for each project deliverable or decision. It eliminates ambiguity about roles and ensures clear communication channels.

## What to Understand
- Key deliverables or decisions requiring assignment
- Who does the work (Responsible)
- Who has final authority (Accountable)
- Who must be consulted (Consulted)
- Who needs to be kept informed (Informed)

## What to Infer
From stakeholder and owner information, infer:
- Natural RACI assignments based on roles
- Standard patterns for the project type
- Escalation paths from RACI structure

## What to Probe (Only if Missing)
- "For key decisions, who needs to approve vs who just needs to know?"
- "Are there any tasks where responsibility is unclear?"
- "Who gets consulted before major changes?"

## Intelligent Behaviors
- Build RACI from existing stakeholder information
- Flag items with multiple Accountables (anti-pattern)
- Suggest missing I's for transparency
- Recommend RACI for contentious areas first
- Connect RACI to communication plan

## Common Pitfalls to Flag
- Multiple people marked as Accountable for same item
- No one marked Accountable
- Too many Consulted slowing decisions
- Key stakeholders not Informed
- RACI created but not followed

## RACI Guidelines
| Letter | Definition | Rule |
|--------|------------|------|
| R | Responsible | Does the work. Can be multiple people. |
| A | Accountable | Final decision authority. ONLY ONE per item. |
| C | Consulted | Two-way communication before decision. |
| I | Informed | One-way communication after decision. |
