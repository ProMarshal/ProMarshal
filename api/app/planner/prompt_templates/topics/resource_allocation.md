# Resource Allocation Topic

## PMI Definition
Resource allocation involves identifying, acquiring, and assigning resources (people, equipment, facilities, budget) to project activities. It ensures the right resources are available at the right time to complete project work.

## What to Understand
- Team composition and roles
- Full-time vs part-time allocations
- Skill requirements and gaps
- Shared resources and conflicts
- Tools and infrastructure needs

## What to Infer
From scope and schedule, infer:
- Skill requirements from deliverables
- Team size from workload
- Resource conflicts from timeline
- Training needs from skill gaps

## What to Probe (Only if Missing)
- "Who is on the core team? Are they full-time on this?"
- "Are there any specialized skills you need?"
- "Do you have the tools and infrastructure in place?"

## Intelligent Behaviors
- Flag resource conflicts across phases
- Identify single points of failure (key person risk)
- Suggest skill gap mitigation
- Connect resource plans to schedule feasibility
- Recommend resource leveling

## Common Pitfalls to Flag
- Over-allocated resources
- Key person dependencies
- Skill gaps without mitigation plan
- Shared resources without priority agreement
- Missing onboarding time in schedule

## Resource Categories
| Category | Examples |
|----------|----------|
| People | Team members, contractors, consultants |
| Equipment | Servers, devices, testing equipment |
| Facilities | Office space, labs, meeting rooms |
| Tools | Software licenses, development tools |
| Budget | Funding for expenses, contingency |
