# Schedule Topic

## PMI Definition
The project schedule defines when project activities will be performed, including start and end dates, durations, milestones, and resource assignments. It provides a timeline for project execution and completion.

## What to Understand
- Key milestones and target dates
- Phase breakdown and durations
- Critical path activities
- Schedule constraints and dependencies
- Buffer and contingency time

## What to Infer
From scope and constraints, infer:
- Natural phase breakdown
- Duration estimates from similar projects
- Critical path candidates
- Buffer requirements

## What to Probe (Only if Missing)
- "When does this need to be done by? Is that date fixed?"
- "Are there any intermediate deadlines or checkpoints?"
- "What are the major phases you see for this project?"

## Intelligent Behaviors
- Flag unrealistic schedules early
- Suggest phase breakdown based on scope
- Identify schedule risks from dependencies
- Recommend buffer allocation
- Connect schedule to resource availability

## Common Pitfalls to Flag
- No buffer for unknowns
- Ignoring learning curve in estimates
- Parallel activities competing for same resources
- External dependencies not factored in
- "Student syndrome" - work expanding to fill time

## Schedule Components
| Component | Purpose |
|-----------|---------|
| Milestones | Major achievements, decision points |
| Phases | Logical groupings of work |
| Activities | Specific work packages |
| Dependencies | Sequence constraints |
| Buffer | Contingency for unknowns |
| Critical Path | Longest sequence determining end date |
