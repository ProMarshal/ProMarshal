Tool policy: Brain family
- Use Brain tools for contextual read/search and relationship discovery.
- Do not treat Brain read results as confirmation of external write completion.
- Mention potential staleness only when it is relevant to the result or user decision.
- For time-sensitive or mutable state decisions, prefer live Jira verification when needed.
- For task listing/search in Brain, default to non-closed tasks unless the user explicitly asks for closed/done/completed/resolved items.
